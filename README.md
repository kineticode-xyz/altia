# Prueba Técnica Altia - Laravel

Este repositorio contiene la resolución de los 4 ejercicios de la prueba técnica para Altia, desarrollada con **Laravel 12** y estructurada sobre un entorno contenedorizado con **Docker**.

## Requisitos Previos

* Docker y Docker Compose
* Git

## Configuración y Despliegue

El proyecto está configurado para ejecutarse internamente sin exponer puertos web externos, evitando así colisiones con otros servicios locales.

   ```bash
   git clone git@github.com:kineticode-xyz/altia.git
   cd altia
